# INFLUENCE: The Influencer Simulator

A responsive, browser-based creator journey simulator built with plain HTML, CSS, and JavaScript. No accounts, paid APIs, or build step required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Publish with GitHub Pages

Push these files to the repository, then in GitHub open **Settings → Pages**. Choose **Deploy from a branch**, select the default branch and `/ (root)`, then save. The site is entirely static and is ready to publish from the repository root.

## Progress and privacy

Simulator progress is saved in the browser's local storage on the current device. The app does not connect to Instagram or transmit profile data. Profile avatar and content imagery are loaded from Unsplash; Google Fonts are loaded from Google Fonts.
